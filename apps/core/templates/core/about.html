This project was built by a group of CDAC Big Data Engineering students to demonstrate how raw Spotify streaming data can be ingested, transformed through a Bronze/Silver/Gold medallion pipeline on AWS S3, and served through a conversational, retrieval-augmented chatbot. The full stack — Postgres with pgvector for retrieval, Redis for caching, and a multi-provider LLM fallback chain — runs live on AWS EC2, grounded end-to-end in real Gold-layer data.
